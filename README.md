# Commercial Maturity Lab website

## Publish on GitHub / Cloudflare Pages
1. Upload `index.html` and the `assets` folder to the repository root.
2. Commit the changes to the `main` branch.
3. Cloudflare Pages will deploy automatically.
4. No build command is required. The output directory is the repository root.

All image assets in this package were generated specifically for Commercial Maturity Lab.
